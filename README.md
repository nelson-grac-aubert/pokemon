# Pokémon Project

A lightweight Pokémon‑inspired prototype built with **Python** and **Pygame**, featuring a simple overworld loop, automatic Pokémon capture, and a JSON‑based collection system.  
This project also served as our first real experience with **object‑oriented programming**.

## 📦 Requirements

### Install Dependencies

This project requires **Pygame**.  
To install it, run:

```bash
pip install pygame
```

## Features

### Overworld Loop

- Basic player movement.
- Simple real‑time game loop using Pygame events.
  
### Automatic Capture System

- Pokémon are automatically captured when encountered.
- Capture logic implemented through modular OOP classes.

### JSON‑Based Collection

- Captured Pokémon are stored in a JSON file.
- Acts as a lightweight Pokédex to track progress.
